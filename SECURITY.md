# Security Policy

## Responsible use

Use this project only against systems you own or are explicitly authorized to test. Start with low traffic and monitor the target infrastructure.

## Reporting a vulnerability

Do not publish security vulnerabilities in a public issue. Email **info@zamandev.ir** with reproduction steps, affected files, impact, and a suggested remediation when available.

## Sensitive data

Never commit real target URLs, credentials, cookies, authorization headers, customer data, or private infrastructure details. Keep local values in ignored environment files and sanitize test reports before sharing them.
